MPVKit is provided by the MPVKit project: https://github.com/mpvkit/MPVKit
Lineup links the MPVKit LGPL product, pinned to 1.1.0-n9.0.2. The separate
MPVKit-GPL product is not included.

The mpv player logo in the app is the official logo from the mpv project:
https://github.com/mpv-player/mpv.io/blob/master/source/images/mpv-logo-128.png
It is used to identify the optional MPVKit playback trial in Lineup.

This trial uses MPVKit's Metal/MoltenVK path. MPVKit describes Metal support as
experimental and says the package is primarily suitable for learning libmpv.
See its README before treating this integration as production-stable.
